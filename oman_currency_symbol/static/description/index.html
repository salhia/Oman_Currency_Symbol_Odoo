OMR Symbol Font | Oman Currency Symbol

Add the official Omani Rial (OMR) symbol to Odoo with a lightweight and clean integration.

Compatible with Odoo 18.0

Overview

This module provides a professional OMR currency symbol font and enables using the Omani Rial symbol across invoices, reports, accounting screens, and printed documents. It is designed to be lightweight, stable, and safe for production environments.

Key Features

  • Official OMR (Omani Rial) symbol support inside Odoo.
  • Works in invoices, reports, accounting views, and PDFs.
  • Lightweight module with clean integration.
  • Easy installation and no impact on existing accounting logic.

Installation

  1. Install the module from Apps.
  2. Update/refresh assets if required.
  3. Use OMR symbol in your documents and reports.

Use Cases

  • Omani organizations requiring official OMR symbol in financial outputs.
  • Invoices, receipts, and accounting reports for local compliance and clarity.
